## 📱 About The Project

**BWhite** is an Android application that allows users to convert colorful images and videos into grayscale. The app provides a clean, intuitive interface and multiple editing options, integrated with **Firebase Authentication** for secure user login and logout functionality.

---

## ✨ Features

- 🔐 **Firebase Authentication**
  - User registration and login system
  - Secure logout functionality

- 🖼️ **Photo Edit**
  - Capture a new photo or select an image from the gallery
  - Convert the selected image to grayscale using **OpenCV**

- 🎥 **Video Edit**
  - Record a fresh video or select an existing video from the gallery
  - Convert the video to grayscale

- 📂 **External Media Edit**
  - Browse and select images or videos from external storage for grayscale conversion

- 🚪 **Logout**
  - Easily sign out of your account from the Logout tab

---
